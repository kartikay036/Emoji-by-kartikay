# Emoji-by-kartikay

Project Description:
The Self-Created Emoji project is a fun and creative front-end development task built entirely using HTML and CSS, without any images or JavaScript. The goal of this project is to design a custom emoji—such as a smiley face—by using basic HTML elements (like <div>) and styling them with CSS to visually represent facial features like eyes, mouth, and the face itself.

This project showcases how simple shapes (circles, arcs, and lines) can be achieved through CSS properties such as border-radius, background-color, positioning, and box-shadow. For example, the emoji face is created with a circular <div>, eyes are made using smaller black circles, and the smile is represented using a semi-circular border or a transformed <div>.

CSS plays a critical role in the appearance and layout. Absolute positioning is used to place facial elements precisely within the emoji face, while other properties like transform, border, and flexbox help achieve a clean and centered design. This project also encourages experimentation with colors, expressions, and layout, allowing students or learners to build different emoji moods like happy, sad, surprised, or wink.

Though simple, this project reinforces core CSS concepts and shows how developers can create visually rich UI components with just markup and styling. It’s an ideal beginner project for practicing front-end design skills without any reliance on external graphics or scripting.
